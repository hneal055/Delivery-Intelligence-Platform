HOW IT WORKS
═══════════════════════════════════════════════════════════════════════

USER EXPERIENCE:
1. Driver sees delivery details in app
2. Taps "Navigate To:" section
3. Sees available navigation apps installed on device
4. Taps preferred app (Waze, Google Maps, etc.)
5. Navigation app launches with destination pre-filled
6. Delivery tracking continues in background
7. Driver can switch between apps anytime

KEY FEATURES:
✅ Real-time GPS tracking continues while navigating
✅ Works in offline mode (Waze/Maps cached)
✅ Automatic fallback if preferred app unavailable
✅ Web fallback if no maps apps installed
✅ Driver can choose preferred navigation app
✅ No new permissions needed

API REFERENCE
═══════════════════════════════════════════════════════════════════════

navigationService.navigateTo(latitude, longitude, label, preference)
  
Examples:
  // Auto-detect best available app
  navigateTo(40.7128, -74.0060, "123 Main St", "auto")
  
  // Force Waze, fallback to Google Maps
  navigateTo(40.7128, -74.0060, "123 Main St", "waze")
  
  // Force Google Maps
  navigateTo(40.7128, -74.0060, "123 Main St", "google")

TECHNICAL DETAILS
═══════════════════════════════════════════════════════════════════════

Deep Link Schemes Used:

Waze (iOS & Android):
  waze://?ll=LATITUDE,LONGITUDE&navigate=yes

Google Maps (iOS):
  comgooglemaps://?daddr=LATITUDE,LONGITUDE&directionsmode=driving

Google Maps (Android):
  google.navigation:q=LATITUDE,LONGITUDE

Apple Maps (iOS):
  maps://maps.apple.com/?daddr=LATITUDE,LONGITUDE&dirflg=d

Web Fallback:
  https://www.google.com/maps/dir/?api=1&destination=LATITUDE,LONGITUDE

No API keys or authentication required.
